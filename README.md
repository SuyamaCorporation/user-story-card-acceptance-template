# User Story Card & Acceptance Criteria Template Builder
Build, preview, and export user story cards with Given-When-Then acceptance criteria.
## Features
- As-a / I-want / So-that inputs to compose a user story
- Add or remove multiple Given-When-Then acceptance criteria rows
- Live Markdown preview updates as you type
- Copy formatted Markdown to clipboard
- Save multiple cards to localStorage and reload them from the sidebar
## Tech
Static SPA · Tailwind CDN · localStorage
